The badge only advertises the companion service and starts its GATT server when SmartphoneBluetoothPairing=true. With it false the badge still shows up in a generic scan but cannot be connected. Whitelisted IDs entered above are saved in this browser; the WHITELISTED_DEVICE_IDS constant is only the default. For GitHub Pages, keep index.html and the certs/ folder together at the site root: certs/client.pem, certs/client.key, certs/root_ca.pem. Those are development credentials only; do not publish root_ca.key or the badge private key. Web Bluetooth needs HTTPS or localhost. Scan 5s uses the experimental BLE advertisement scan API. Chrome may need chrome://flags/#enable-experimental-web-platform-features.
